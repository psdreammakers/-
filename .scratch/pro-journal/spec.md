# 交易日誌第一版

Status: ready-for-agent

詞彙以倉庫根目錄 `CONTEXT.md` 為準。走位以線框 [prototype-walk.html](prototype-walk.html) 為準。決定見 `docs/adr/` 與地圖 [map.md](map.md)。

## Problem Statement

我在複盤美期當沖，需要一本自己的日誌：看這段時間賺沒賺、哪種做法在賺、哪天發生什麼、哪筆單我怎麼做的、情緒有沒有劫持決策。現況那張 GoodSheet 是記帳，不是這本。我不連券商、不在 K 線上標進出場。程式要能掛到公開網站給別人用同一套，但每人的帳只活在自己的瀏覽器。

## Solution

做成一個中文的個人交易日誌網站。頂欄寫「交易日誌」，瀏覽器分頁寫 YC's Trading Journal。頂欄兩本：指揮中心、心理戰。指揮中心上有數字、權益線、損益月曆、時段熱力圖、分解表、交易報告卡清單。點月曆或曲線某一天打開當日日誌（盤前、盤後、當日背景、經濟事件、當天的交易）。交易報告卡是一筆單的複盤單位，可手貼最多三張圖。經濟事件從站內日程表對上該交易日自動出現。資料只存在這台瀏覽器。第一次打開帶示範資料；存下第一筆真的單之後示範資料清掉。

## Implementation Decisions

- 這是新的交易日誌本，不是把現況 GoodSheet 的 localStorage 遷過去。舊鍵、舊欄、舊「策略」標不當約束。
- 上架是靜態網站（GitHub Pages 這類）：公開的是程式。每人一份本機紀錄。沒有登入、沒有伺服器上的帳本。
- 介面中文。頂欄產品名「交易日誌」。文件標題／分頁「YC's Trading Journal」。
- 頂欄只有兩本：指揮中心、心理戰。損益月曆、交易報告卡清單、分解表、時段熱力圖、權益線都長在指揮中心。
- 走位以線框為準（來自 prototype-walk.html）：月曆獨立（點一天只開當日日誌）。分解表、時段熱力圖、交易報告卡清單三件聯動。權益線可指可點進當天，不改那三件的篩選。報告卡與心理遊戲用欄位，側欄打開，不是一段敘事。
- 市場鎖定美期。商品短清單，鍵為根代號，出廠 MNQ、MES，設定可加減。單位口。交易日＝America/New_York 的日曆日。
- 只一層方法名：setup 標。出廠突破／回歸／開盤區間。每筆必選剛好一個。設定可加減。沒有策略層。
- 帳戶短清單，出廠「主帳戶」，每戶初始資金美元可 0。切單一帳戶才有目前權益、初始資金、權益線。全部帳戶只加總交易數字。
- 交易報告卡必填與可空欄見地圖「交易報告卡第一版必填欄位」。損益手打。成績與執行評等皆 A–F。
- 截圖：只屬於交易報告卡，0–3 張，本機，打開卡才渲染。清單無縮圖。當日日誌不存圖。
- 指揮中心數字與篩選見地圖「指揮中心第一版有哪些數字」。另加大卡風報比＝平均賺÷|平均賠|（走位票補上，與賺賠比不同）。不做夏普、R、MFE／MAE。
- 分解表切換全部／setup／商品／成績。成績展示 A–D 四列（空列仍在）。報告卡仍可打 E／F。累積權益是列終點，不是目前權益。
- 當日日誌一天一頁：當日背景一句；盤前三欄可空；盤後兩句可空；當天交易正序列出；經濟事件區；綁當天的心理遊戲。
- 日程表是程式內的共用日期本，手維。列：時間、名稱、機關、官方連結、所屬交易日。覆蓋：FOMC 聲明、FOMC 記者會（同日兩列）、BLS Employment Situation、BLS CPI、BEA GDP 三次估計、BEA 個人所得與支出。不是規則引擎，不是 ICS 直拉，不是 GitHub Actions 烘焙。表上有一份日程表核對日，事件區顯示它。
- 經濟事件對上當日日誌：日程表該日之列自動出現。本機可在列上填 impact／實際／預估。可另增當日手填列，不回寫日程表。
- 心理遊戲：類型固定七個（含其他），強度 1–10，二者擇一綁報告卡或當天。說明一句；其他則必填。
- 示範資料：本機尚無任何真的交易報告卡時載入並標示範。第一筆真的報告卡寫入後刪除示範資料，不可並存。不是可切換的示範帳戶。
- 本機紀錄至少包含：設定（帳戶／商品／setup 標／初始資金）、交易報告卡（含截圖位元）、當日日誌欄位、心理遊戲、經濟事件的本機填寫（impact 等與手填列）。日程表本身是程式的一部分，不是帳戶資料。

## Testing Decisions

- 只測對外行為，不測畫面怎麼排、不測儲存用什麼鍵、不測舊 GoodSheet。
- 唯一接縫：交易日誌本。測試以這份本為主詞：寫入帳戶／報告卡／當日日誌／心理遊戲／手填經濟事件／截圖，讀出指揮中心數字、權益線點、損益月曆日格、熱力圖格、分解表列、某交易日的經濟事件、示範資料是否還在。
- 必測的行為例子：淨損益把空手續費當 0；全部帳戶沒有目前權益；單戶加 setup 篩選時權益線只加篩進的筆；時間篩選時起點含區間前損益；熱力圖沒單空白、有單 0 顯示 0；分解表成績四列即使為零；日程表只在對上的交易日出現 FOMC 兩列；空本有示範資料、寫入真單後沒有；心理遊戲不雙綁；截圖超過 3 張進不了報告卡；報告卡缺必填欄不能當成一筆。
- 現況程式沒有測試。新測試只打這條接縫，不要為了測而拆一堆模組。
