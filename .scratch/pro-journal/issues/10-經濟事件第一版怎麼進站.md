# 經濟事件第一版怎麼進當日日誌

Type: grilling
Status: resolved
Blocked by: 01

## Question

[經濟日曆自動灌入的來源與限制](06-經濟日曆來源與限制.md) 已鎖事實：自動欄只有時間／名稱／機關／連結；瀏覽器直拉目前只有 BEA ICS；FOMC、BLS、EIA、台灣主計總處／央行有官方表但沒 CORS；GitHub Actions 烘焙能過閘，但寫回倉庫要人確認。

在「市場與商品」鎖完後，第一版用哪條車道？

1. **只拉會動的**：例如美盤只接 BEA ICS，其餘（FOMC 八個日期、EIA 週三規則）寫成手維表。
2. **官方表手維**：你在用的那幾個機關，做成站內固定表，偶爾對官方頁。
3. **GitHub Actions 烘焙**：CI 拉官方 ICS／HTML 寫成站內 JSON（上架／自動化要你點頭）。
4. **第一版可手填一列就好**，自動灌入留到有烘焙再說。

impact／實際／預估維持選填手填，不進自動欄。台灣官方表不當這本的自動灌入（市場已鎖美期）。

## Answer

第一版用站內共用日程表，跟程式一起走，偶爾對官方頁改表。不直拉 BEA ICS，不開 GitHub Actions 烘焙，不靠當天早上手打當本。

打開該交易日，對上的列已經在。只這些項：FOMC 聲明、FOMC 記者會（同一天兩列）、BLS Employment Situation、BLS CPI、BEA GDP（三次估計）、BEA 個人所得與支出。不要 EIA，不要 BEA 其他項。

表是一列一個已公布日期：時間、名稱、機關、官方連結。不是週次規則。連結是官方日程或產品頁，公布後第一版不改連結。

事件區標日程表核對日。沒有現場「未能自動更新」。多數交易日沒列是正常。

impact／實際／預估仍選填，可寫在自動出現的列上，只活在本機。官方表沒列到的，當天可手填多列，不寫回日程表。當日背景不扛發布日程。指揮中心不做即將發布小曆。

詞彙已更新 `CONTEXT.md`：經濟事件、日程表、日程表核對日。決定見 [ADR](../../docs/adr/0001-hand-maintained-release-schedule.md)。
