# 指揮中心第一版有哪些數字

Type: grilling
Status: resolved
Blocked by: 07

## Question

指揮中心是績效總覽。現況已有：初始資金、權益、筆數、淨損、平均賺、平均賠、勝率、總賺／總賠、最大賺、最大賠、夏普、資金曲線。Tanto 還有報酬風險比、熱力圖、MFE／MAE。

MFE／MAE 圖表層已排除。在報告卡欄位鎖完後，第一版指揮中心要哪些數字、哪些確定不做（例如沒有停損就沒有 R）？

已知：每筆必有帳戶；每戶自己的初始資金；切帳戶換權益線。篩選刀已有：帳戶、商品、setup 標。淨損益＝平倉損益−手續費（空＝0）。計畫風險可空，R 只能算有填的筆。沒有 RTH 欄，時段若要熱力圖用美東時間切。

## Answer

單帳戶顯示：目前權益、初始資金、權益線、累積損益、筆數、勝率、平均賺、平均賠、期望值、賺賠比、最大單筆賺、最大單筆賠、總手續費。

全部帳戶只加總交易數字（累積損益、筆數、勝率、平均賺、平均賠、期望值、賺賠比、最大單筆賺、最大單筆賠、總手續費）。不顯示目前權益、初始資金，不畫合成權益線。各戶權益留在自己帳戶裡。熱力圖與分解表在全部帳戶仍顯示。

勝率＝賺錢筆數÷全部筆數（含平盤）；平盤不進勝也不進敗；懸停看勝／敗場。賺賠比＝總賺÷|總賠|，懸停看兩個金額。期望值＝累積損益÷筆數。總手續費＝各筆手續費加總（空＝0）。最大賺賠是單筆，不是單日。

篩選刀：帳戶、商品、setup 標。時間區間仍在。單帳戶再加商品／setup 篩選時，權益線從該戶初始資金起算、只加篩進的筆（「只做這些」，不是券商餘額）。時間篩選時，權益線起點＝初始資金＋區間之前的淨損益。

熱力圖：美東星期×24 小時；格子＝該格累積損益；沒交易空白；有交易而損益 0 才顯示 0。不裁成只顯示 RTH。

分解表：一張表，切換 setup 標／商品／成績。每列筆數、累積損益、勝率、期望值。成績不當第四把篩選刀。執行評等、多空不進這張表。點列、點熱力圖怎麼走位不在這張票。

不做：夏普、平均 R／報酬風險比、MFE／MAE、勝率儀表裝飾。

詞彙已寫入 `CONTEXT.md`：目前權益、分解表；帳戶補上全部帳戶不合成權益。
