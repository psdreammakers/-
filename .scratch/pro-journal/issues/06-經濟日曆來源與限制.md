# 經濟日曆自動灌入的來源與限制

Type: research
Status: resolved

## Question

在沒有券商連結、本機可記、GitHub Pages 上架的前提下，當日日誌要自動灌入該日經濟事件。哪些來源在授權、CORS、更新頻率、時區、覆蓋市場上實際可用？靜態前端能怎麼取、有哪些不能做？

調查範圍包括美盤（利率、就業、通膨、能源）、外匯常見貨幣、台灣（若有公開日曆）。每個候選來源必須追到第一方條款或官方文件，不要轉述部落格。

產出應讓後續規格能寫下：用哪類來源、資料在哪裡過期、失敗時當日日誌長什麼樣。

## Answer

靜態 GitHub Pages 前端不能當 Forex Factory 用。跨站 `fetch` 多數官方 HTML 沒 CORS；商業日曆 API 有欄位但個人授權禁止公開展示，金鑰也會漏在瀏覽器。本次唯一證實「無金鑰、官方日程、瀏覽器可直拉」的是 BEA 的 ICS（`Access-Control-Allow-Origin: *`，時區 America/New_York）。美盤其餘（FOMC、BLS CPI/NFP、EIA 週三 10:30 ET）與台灣主計總處／央行預告表授權開、CORS 不開——要嘛內建規則／手維，要嘛 GitHub Actions 烘焙成站內 JSON（這條是小代理的替代，不是預設伺服器）。官方日程只有時間＋名稱＋機關，沒有 impact／actual／forecast。失敗時日誌本體照寫，事件區顯示「未能自動更新」＋上次成功時間＋官方連結＋手填，不要空白假裝今日無事。過期點＝最後一次成功寫進 ICS／站內 JSON 的時刻。
