# 15: 損益月曆與當日日誌

**What to build:** 指揮中心上的損益月曆以日為格、綠紅加週合計。點一天打開當日日誌（可全空）：當日背景、盤前三欄、盤後兩句、當天交易報告卡按時間正序。點月曆不改分解表／熱力圖／交易表的篩選。當天表點列打開同一張報告卡。

**Blocked by:** 13: 空本可記第一筆交易報告卡

**Status:** ready-for-agent

- [ ] 損益月曆長在指揮中心；日格綠紅、有週合計；交易日是美東日曆日
- [ ] 點一天打開當日日誌；沒交易的日子也有頁、可全空
- [ ] 點月曆不聯動分解表、時段熱力圖、交易報告卡清單
- [ ] 當日背景單獨一欄，可空；盤前三欄可空（風險上限美元、今天只做哪些 setup 標可多選、一句計畫）；盤後兩句可空（做得好的一件、明天只改一件）；不是富文本
- [ ] 當天交易報告卡全部自動列出、不用勾選、按時間正序；點列打開同一張報告卡欄位
- [ ] 當日日誌不依商品切開；沒有預測／實際、沒有斜線指令嵌交易
- [ ] 測試打交易日誌本：某交易日讀出的背景／盤前／盤後／當日交易清單與寫入一致
