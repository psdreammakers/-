# 專業交易日誌規格

Label: wayfinder:map
Status: closed（2026-09-21 補欄：01–12 決定票全收，13–20 實作票 2026-09-10 已併入主線並上架）

## Destination

一份可交接的規格：就這座做成新的個人交易日誌網站（本機可記、可上架）。四面為指揮中心、損益月曆、交易報告卡、當日日誌（含經濟事件自動灌入）；心理戰是獨立的心理遊戲診斷本。不做券商同步、不做 K 線標進出場。

## Decisions so far

- [經濟日曆自動灌入的來源與限制](issues/06-經濟日曆來源與限制.md)：自動灌入只能是官方發布日程（時間＋名稱＋機關＋連結），不是 Forex Factory 那種 impact／實際／預估表。瀏覽器直拉目前只有 BEA ICS 證實可行；其餘官方表要手維或 GitHub Actions 烘焙。失敗時日誌照寫，事件區要說失敗，不能空白假裝無事。詳見 [調查](research/economic-calendar.md)。
- [這本日誌記哪種市場與商品](issues/01-市場與商品.md)：第一版只記美期；每筆必選商品；出廠 MNQ、MES；根代號不含月份；交易日跟美東日曆日。
- [心理遊戲記什麼類型、何時寫](issues/02-心理遊戲類型與何時寫.md)：只在劫持時寫；類型固定六個＋其他；強度 1–10；有交易就綁報告卡（當天靠日期列出），沒有才綁當天；一句選填、其他必填。
- [非經濟的外在衝擊還要不要記](issues/03-非經濟外在衝擊.md)：當日日誌一句當日背景（斷線／會議／資金／生活／跳空），有事才寫；不另立本，不加進心理遊戲。
- [策略與 setup 是不是同一層](issues/04-策略與setup是不是同一層.md)：只留 setup 標一層；每筆必選一個；清單可改；出廠突破／回歸／開盤區間；跨商品。
- [當日日誌盤前盤後固定欄](issues/05-當日日誌固定欄.md)：一天一頁不依商品切；背景單獨欄；交易全列出；盤前三欄可空（美元風險上限／setup 計畫／一句計畫）；盤後兩句可空；點月曆就有頁。
- [交易報告卡第一版必填欄位](issues/07-報告卡第一版必填欄.md)：必填含帳戶／成績／執行評等／方向／口數／損益；價與停損可空；每戶自己的初始資金；切帳戶換權益線。
- [指揮中心第一版有哪些數字](issues/08-指揮中心第一版數字.md)：單帳戶才有目前權益／初始資金／權益線；全部帳戶只加總交易數字。要熱力圖（美東星期×小時、格子累積損益）與分解表（setup／商品／成績）。有總手續費、期望值、賺賠比。不做夏普、R、MFE／MAE。
- [四個面加心理戰怎麼走位](issues/09-四面加心理戰怎麼走位.md)：頂欄指揮中心＋心理戰。月曆與報告卡清單長在指揮中心。月曆獨立；分解表／時段熱力圖／交易表三件聯動。曲線可指可點進當天。細節用欄位。線框 [prototype-walk.html](prototype-walk.html)。
- [經濟事件第一版怎麼進當日日誌](issues/10-經濟事件第一版怎麼進站.md)：站內手維日程表；打開當天對上的列已在。只 FOMC 聲明＋記者會、非農、CPI、GDP／PCE。標核對日。可手填多列。不直拉、不烘焙。
- [截圖第一版要不要、貼在哪](issues/11-截圖要不要貼哪.md)：只交易報告卡可手貼，可空，一筆最多 3 張。圖只住這台瀏覽器。打開卡才看得到。當日日誌不貼，清單不縮圖。
- [產品第一版叫什麼](issues/12-產品第一版叫什麼.md)：頂欄「交易日誌」，分頁 YC's Trading Journal。程式公開、資料各人本機。空站帶示範資料，真單進了就清掉。

## Out of scope

- 券商自動同步（沒有連結，且目的地已排除）
- K 線上標進出場、MFE／MAE／Captured % 圖表層（沒有行情連結）
- 多人、學生、示範帳
- 把現有 localStorage 完整遷入當成規格前提（可丟）
- 複製 Tanto 的付費、35 家券商、語音輸入
- 用 Forex Factory／Investing.com 刮站，或把 Finnhub／FMP／Trading Economics 個人金鑰塞進公開 Pages 當日曆本（授權與 CORS 都不合）
- 台灣主計總處／央行日曆自動灌入（市場已鎖美期，日曆跟美東）
- 第一版直拉 ICS 或 Actions 烘焙日曆（灌入已決手維表）
- EIA 原油週報進日程表
- 指揮中心做即將發布小曆
- 當日日誌貼圖；圖上架或進倉庫；清單縮圖
- 上架後別人看到你的帳；登入多人（已決程式公開、資料各人本機）
