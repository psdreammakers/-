# 19: 心理戰可記心理遊戲

**What to build:** 心理戰本可在情緒劫持決策時記心理遊戲。類型固定、強度 1–10；有對應交易就綁那張報告卡，還沒成交才綁當天。從報告卡、當天日誌、心理戰本都能走進同一則。

**Blocked by:** 13: 空本可記第一筆交易報告卡, 15: 損益月曆與當日日誌

**Status:** ready-for-agent

- [ ] 只在劫持時寫；同一天、同一筆都可以多則；沒有每日一則上限
- [ ] 二者擇一：有單綁報告卡（當天靠交易日列出），沒單才綁當天；不雙綁；整天＋那筆都要記就寫兩則
- [ ] 類型固定：想翻本、怕錯過、怕虧、犯錯怒、覺得不公平、覺得自己該贏、其他；設定裡不能加減
- [ ] 強度必填 1–10；一句說明選填；選「其他」則這句必填
- [ ] 從報告卡、當天日誌、心理戰本走進同一則；細節是欄位不是一段話
- [ ] 睡不好、破規則、加碼、斷線不是心理遊戲類型
- [ ] 測試打交易日誌本：綁卡與綁當天的讀出位置正確；雙綁進不去
