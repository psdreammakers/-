# 17: 經濟事件從日程表進當日日誌

**What to build:** 打開某交易日，站內日程表對上那天的經濟事件已經列在當日日誌。第一版只含 FOMC 聲明與記者會（同日兩列）、Employment Situation、CPI、GDP 三次估計、個人所得與支出。事件區標日程表核對日。可手填多列與 impact／實際／預估（本機）。不直拉 ICS、不烘焙。

**Blocked by:** 15: 損益月曆與當日日誌

**Status:** ready-for-agent

- [ ] 日程表跟程式走，一列一個已公布日期：時間、名稱、機關、官方連結；不是週次規則
- [ ] 自動出現只這幾項：FOMC 聲明、FOMC 記者會（同一天兩列）、BLS Employment Situation、BLS CPI、BEA GDP 三次估計、BEA 個人所得與支出；不要 EIA、不要其他 BEA 項
- [ ] 打開對上的交易日，列已經在；多數交易日可以一列都沒有
- [ ] 事件區標日程表核對日；沒有「未能自動更新」
- [ ] 自動列上可選填 impact／實際／預估，只活在本機；官方表沒列到的當天可手填多列，不寫回日程表
- [ ] 當日背景不拿來記發布日程；指揮中心不做即將發布小曆
- [ ] 連結是官方日程或產品頁；測試打交易日誌本：給定日程表與交易日，讀出的經濟事件列集合正確
