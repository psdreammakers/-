# 心理遊戲記什麼類型、何時寫

Type: grilling
Status: resolved

## Question

心理戰已定為 Tendler 式診斷本：不是每天三張表，而是情緒劫持決策時才記。尚未鎖的是類型清單與觸發規則。

現有中文標籤（想翻本、怕錯過、破規則、心煩…）是半成品。Tendler 常用類型包括：恨虧、犯錯怒、覺得不公平、想翻本、覺得自己該贏、各種怕（錯過、虧、錯、失敗）。

請決定：

1. 第一版固定哪些類型（中文名稱，可對到 Tendler，但不必全收）
2. 何時寫：只在出事時／每筆都可選填／每天最多一則
3. 一則是綁交易報告卡、綁當天、或兩者都可
4. 強度要不要（例如 1–10）

## Answer

只在情緒劫持決策時才寫。不是每筆選填，也沒有每日一則上限。同一天、同一筆都可以多則。

一則二者擇一：有對應交易就綁報告卡，當天靠交易日自動列出；還沒成交才綁當天。整日＋那筆都要記，寫兩則。不雙綁。

強度必填 1–10。第一版類型固定：想翻本、怕錯過、怕虧、犯錯怒、覺得不公平、覺得自己該贏、其他。設定裡不能加減。一句說明選填；選「其他」則這句必填。不是一小段，不是長文。

不當心理遊戲：睡不好／過勞／趕時間、破規則／加碼／提前出場、斷線／會議／生活事件。
