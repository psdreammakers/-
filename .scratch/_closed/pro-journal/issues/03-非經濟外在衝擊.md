# 非經濟的外在衝擊還要不要記

Type: grilling
Status: resolved

## Question

舊心理戰第三本「事件」混了兩種東西：市場公布（現在改由經濟日曆自動灌入）以及非經濟衝擊（斷線、會議、資金異動、生活事件、跳空）。

經濟事件已歸當日日誌。這些非經濟衝擊還要不要有位置？

選向大致是：

1. 不要。只留經濟事件＋心理遊戲。
2. 當日日誌裡一個手動「當日背景」句，不另立本。
3. 心理戰裡可選「外在衝擊」類型（生活／斷線／會議），仍只在出事時寫。

## Answer

要記，但不另立本，也不加進心理遊戲。

位置：當日日誌裡一句當日背景。這句可以寫斷線、會議、資金異動、生活事件、跳空。有事才寫，可空。不是每個交易日必填。

這句掛盤前還是單獨一欄，留給「當日日誌盤前盤後固定欄」。

詞彙已寫入 `CONTEXT.md`：當日背景。
