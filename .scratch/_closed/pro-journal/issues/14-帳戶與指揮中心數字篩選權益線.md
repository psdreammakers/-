# 14: 帳戶與指揮中心數字、篩選、權益線

**What to build:** 設定裡可加減帳戶、商品、setup 標；每戶有自己的初始資金。單看一戶時指揮中心有目前權益、初始資金、權益線，以及規格裡的交易數字。看全部帳戶時只加總交易數字，不顯示目前權益、不畫合成權益線。可用帳戶／商品／setup／時間篩選；單戶再加篩時權益線從該戶初始資金起算、只加篩進的筆。

**Blocked by:** 13: 空本可記第一筆交易報告卡

**Status:** ready-for-agent

- [ ] 設定可加減帳戶／商品／setup 標；每戶初始資金美元可 0；切帳戶換那一條權益線
- [ ] 單帳戶顯示：目前權益、初始資金、權益線、累積損益、筆數、勝率、平均賺、平均賠、期望值、賺賠比、風報比、最大單筆賺、最大單筆賠、總手續費
- [ ] 期望值＝累積損益÷筆數；賺賠比＝總賺÷|總賠|；風報比＝平均賺÷|平均賠|；勝率＝賺錢筆數÷全部筆數（含平盤），平盤不進勝也不進敗
- [ ] 全部帳戶不顯示目前權益與初始資金、不畫合成權益線，但仍加總交易數字
- [ ] 篩選刀：帳戶、商品、setup 標、時間區間；單戶加商品／setup 篩選時權益線只加篩進的筆
- [ ] 時間篩選時權益線起點＝初始資金＋區間之前的淨損益
- [ ] 不做夏普、平均 R、MFE／MAE
- [ ] 測試打交易日誌本：同一組報告卡讀出的數字與權益線點符合上面定義
