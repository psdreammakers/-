# 這本日誌記哪種市場與商品

Type: grilling
Status: resolved

## Question

這本日誌第一版要記哪一種市場、哪些商品？

現況記帳沒有商品欄，只記帳戶／策略／平倉損益。經濟日曆、報告卡欄位（口數或股數、合約、時段）、當日日誌要不要分商品，都掛在這題。

請鎖到可寫進規格的程度：市場（美期／外匯／台股／台指／其他）、主要商品清單、是否多市場並行。

## Answer

第一版只記美期，不並行台指、台股、外匯。

每筆交易報告卡必須從短清單選一個商品；不能自由打字，也不能不記。出廠清單是 MNQ、MES，設定裡可加減。鍵是根代號，中文名（納指微／標普微）只當說明。

商品只到根代號：換月仍是 MNQ，不是 MNQH6。月份不進清單、不當篩選主鍵。單位是口。時段（RTH／ETH）不是商品的屬性。

交易日＝美東（紐約當地，冬夏令跟著切）的日曆日 0:00–24:00。不用台灣日期，也不用 Globex 交易日。
