# 當日日誌盤前盤後固定欄

Type: grilling
Status: resolved

## Question

當日日誌的骨架已定：盤前計畫、盤後複盤、可把當天交易嵌進筆記、該日經濟事件自動出現。尚未鎖固定欄。

Tanto 的當日日誌還有：富文本、最多三個商品的預測／實際、斜線指令嵌交易。預測／實際已從這張地圖的最小骨架拿掉，不表示以後不能加。

請鎖第一版必填／選填：

- 盤前：例如風險上限、今天只做哪些 setup、一句計畫
- 盤後：例如做得好的一件、明天只改一件
- 交易怎麼嵌：清單勾選／從報告卡反連
- 要不要商品分段（這題可與「市場與商品」對看，但先寫你會填的欄）
- 當日背景：已定為一句、有事才寫、可空；這張票要鎖它掛盤前還是單獨一欄

經濟事件面板已有調查結論：自動只有時間／名稱／機關／連結；失敗要明示。不必在這張票重開來源，但盤前／盤後欄不要把 impact、實際、預估當成自動欄。

## Answer

不依商品切開。同 setup 標在不同商品的表現由指揮中心篩。

當日背景單獨一欄，有事才寫。當天交易報告卡全部自動列出，不用勾選。

盤前三欄皆可空：風險上限（當天最多虧多少美元）、今天只做哪些 setup 標（可多選，只是計畫）、一句計畫。盤後兩句皆可空：做得好的一件、明天只改一件。不是富文本。

點損益月曆一格就有當日日誌，可全空；沒交易也可以看經濟事件、寫盤前。

第一版沒有預測／實際、沒有斜線指令嵌交易。
