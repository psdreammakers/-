# 策略與 setup 是不是同一層

Type: grilling
Status: resolved

## Question

現況有「策略」標籤（A／B／C…），記帳必選，曲線與月曆可篩。Tanto 的 03 用 setup 標（突破、回歸…）篩「哪種方法在賺錢」。

這兩層是同一件事換名字，還是兩層都要？

例如：策略＝你的系統名稱（開盤區間、均值回歸）；setup＝該系統裡的具體形態。若只留一層，規格裡只准一個詞。

## Answer

只留一層，叫 setup 標。規格不再另設「策略」。現況那一格換這個詞。

每筆交易報告卡必選剛好一個。清單可在設定裡加減。出廠：突破、回歸、開盤區間。沒有「其他」。setup 標跨商品，不寫成「MNQ 突破」。
