# 18: 交易報告卡可手貼截圖

**What to build:** 交易報告卡可以手貼 0 到 3 張圖，不貼也能存。圖只出現在打開的那張卡上；指揮中心清單與當日日誌那一頁沒有縮圖。圖只住這台瀏覽器。沒有自動抓圖、沒有在圖上標進出場。

**Blocked by:** 13: 空本可記第一筆交易報告卡

**Status:** ready-for-agent

- [ ] 一筆最多 3 張、可 0 張；第四張進不去
- [ ] 打開報告卡才看得到圖（從指揮中心清單點列，或從當日日誌當天表點列，同一張卡）
- [ ] 清單列上不放縮圖；當日日誌不貼圖
- [ ] 圖只活在這台瀏覽器，不上傳、不進倉庫
- [ ] 沒有自動抓圖、沒有在圖上標進出場
- [ ] 測試打交易日誌本：寫入 0／3 張能讀回；第 4 張被拒
