# 四個面加心理戰怎麼走位

Type: prototype
Status: resolved
Blocked by: 02, 05, 07

## Question

規格裡的走位要具體到能畫一張圖：指揮中心、損益月曆、交易報告卡、當日日誌、心理戰，人怎麼從一面走到另一面？

點月曆的一天會看到什麼？報告卡從哪裡打開？心理戰一則怎麼連到交易或當天？當日日誌怎麼嵌交易？

用便宜的線框或紙原型回答「怎麼走」，不要做真網站。

## Answer

頂欄兩本：指揮中心、心理戰。損益月曆與交易報告卡清單不另開頂欄，都長在指揮中心。

指揮中心（訂版線框 [prototype-walk.html](../prototype-walk.html)）：
- 上：目前權益、累積損益、勝率、賺賠比、風報比（大卡，平均賺÷|平均賠|）、筆數；旁邊統計（期望值、平均賺／賠、最大單筆、總手續費）。單帳戶才有目前權益／初始資金／權益線。
- 權益線：滑過看那天的日期、權益、當日損益、筆數；點進去當日日誌。不改下面三件的篩選。
- 損益月曆：綠紅日格＋週合計。獨立。點一天只開當日日誌，不聯動分解表／熱力圖／交易表。
- 三件聯動（只這三件）：分解表、時段熱力圖、交易報告卡清單。點分解表列或熱力圖格，另外兩件跟著變。

分解表切換：全部／setup／商品／成績。成績四列 A B C D（沒單也在）。欄：主標題、筆數、勝率、期望值、平均賺、平均賠、賺賠比、風報比、累積權益（該戶初始＋該列損益）。點欄名排序，預設累積權益大→小。

時段熱力圖：美東星期×24 小時，格子累積損益，沒單空白。

交易報告卡清單欄：時間、帳戶、商品、setup、方向、口數、成績、執行、損益。點欄名排序，預設時間新→舊。點列打開報告卡欄位（不是一段話）。

當日日誌：點月曆或曲線那天打開。欄位：當日背景、盤前三欄、盤後兩句、當天交易表、綁當天的心理遊戲。當天交易按時間正序，不跟總表排序。

心理戰：獨立本。有交易綁報告卡，沒有才綁當天。從報告卡或當天日誌或心理戰本走進一則。

細節一律欄位，不要寫成一段話。

成績：分解表固定 A–D。報告卡必填成績在 [交易報告卡第一版必填欄位](07-報告卡第一版必填欄.md) 仍寫 A–F；這張走位票不改那張的必填字母，只鎖分解表四列。
